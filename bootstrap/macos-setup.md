# Mac Codex Bootstrap

1. Clone or copy this repository onto the Mac.
2. Read `README.md`.
3. Read `AGENTS.md`.
4. Read `Projects/nlm/PROJECT.md` and `Projects/nlm/HANDOFF.md`.
5. Install the skills by running `bootstrap/install-skills.sh`.
6. Confirm the skills are present under `~/.agents/skills/`.
7. Read `Projects/nlm/docs/google-docs-bridge.md` if you need Google Docs bridge access.
8. Use the shared Google Docs `Agent Bridge` workflow for cross-machine messages.

If any path differs on the Mac, keep the same structure and update the local paths only.
