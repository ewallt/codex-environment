# Handoff Template

Use this as the shape of the handoff before compaction.

## What We Are Working On

One short paragraph on the current active work.

## What Was Just Done

Bullets for the most recent milestone or decision.

## What Matters Most After Compact

Bullets for the latest context, open loops, file paths, tool state, and anything the next session would otherwise have to re-derive.

## Next Step

State the next action explicitly. If nothing specific is queued, say that clearly.

## Style

- Keep it factual.
- Keep it short.
- Put the newest and most relevant context first.
- Do not narrate the whole session.
