# Post-Compact

Use this skill when the session has compacted or when Tom asks you to resume from a handoff.

## Workflow

READ NOW: `C:\Users\tomew\Documents\codex-test\Projects\nlm\HANDOFF.md`

Use the handoff as the primary source of truth for where the work stopped.

READ NOW: `C:\Users\tomew\Documents\codex-test\Projects\nlm\WORKLOG.md`

Check the log for anything notable that happened after the handoff was written.

READ NOW: `C:\Users\tomew\Documents\codex-test\Projects\nlm\PROJECT.md`

Use the project doc for stable context, paths, and standing rules.

## Reorientation

Before doing new work, restate for yourself:

- what we are working on
- what was just completed
- what changed most recently
- what the next step is

If the handoff and worklog disagree, prefer the most recent log entry or the most recent explicit instruction from Tom.

## Rule

Do not resume from memory alone. Rebuild the working state from the handoff, log, and project doc before proceeding.
