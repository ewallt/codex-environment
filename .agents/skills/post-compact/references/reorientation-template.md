# Reorientation Template

Use this after compacting before doing more work.

## What We Are Working On

One short paragraph on the active task.

## What Changed Most Recently

Bullets for the latest completed milestones or decisions.

## What Matters Now

Bullets for the latest open loop, file paths, tool state, or constraints.

## Next Step

State the next action explicitly. If nothing is queued, say that clearly.

## Style

- Keep it factual.
- Keep it short.
- Do not rely on stale session memory.
